    RZECZYWISTE ZADANIA API

    Work

    Work połączy się z API po otwarciu widoku.

    Zadania są trwale zapisywane w API do przeglądu. Wybranie opcji „Zatwierdź analizę Ollama” kieruje je do niezależnego workera, gdy działa serwer. Worker generuje raport do wglądu, ale nie wykonuje kodu, nie zatwierdza zakupów ani nie łączy PR. Opcja „Wyślij do AI” przekazuje wybrane zadanie do oryginalnego serwera agentów po sprawdzeniu autoryzacji i zgodności API. Nie nadaje agentom stałych ról ani własnych instrukcji.

    Instalacja i połączenie MCP

    Poniższe polecenia uruchamiasz w terminalu hosta lub Codespaces. Nie wymagają wklejania klucza OpenAI API do kodu. Korzystanie z Codexa zależy od dostępnych limitów planu.

    codex --version
codex login
python3 debian13/system/mcp_autoconfigure.py --check
python3 debian13/system/mcp_autoconfigure.py --install-codex
codex mcp list

    Autokonfigurator sprawdza lokalny serwer MCP i rejestruje mostek stdio tylko po Twoim wywołaniu. Token API pozostaje w prywatnym pliku. Wymagana jest uruchomiona aplikacja Debian 13.
